## Download & Install

> Setup notes for **BCD Edit Repair Tool** on Windows 10/11 (64-bit). Run the repair tool as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **BCD Edit Repair Tool** from the Start menu

## What you can use it for

- Scan and repair Windows issues with BCD Edit Repair Tool
- Fix registry, startup, and junk file problems
- Restore broken shortcuts and system settings
- One-click maintenance for slow or unstable PCs
- Backup critical settings before applying fixes
